📨 Форма обратной связи

Эта форма отправляется на POST /submit и проходит через конвейер: Logging → Timing → FormValidation → Endpoint. Невалидные данные middleware отклонит сам (short-circuit), валидные — дойдут до endpoint.

Что показать преподавателю:

  1. Отправьте пустую/невалидную форму → ответ 400 от FormValidationMiddleware.
  2. Отправьте валидную форму → страница успеха от endpoint POST /submit.
  3. Откройте F12 → Network → проверьте заголовки X-Logged-By, X-Response-Time-ms, X-Lifecycle-Stage.
  4. Посмотрите консоль сервера — там весь жизненный цикл по шагам.
